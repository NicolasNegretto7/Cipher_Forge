# 9. Control de Cambios Técnicos

## ¿Para qué sirve este documento?

Este documento registra exclusivamente los cambios tecnológicos, de implementación e infraestructura realizados durante el desarrollo del proyecto **Cipher_Forge**. Difiere del [Control de Cambios general](08_control_de_cambios.md), que documenta cambios de alcance, documentación y decisiones de producto.

Los cambios registrados aquí afectan código fuente, configuración de infraestructura, estructura de base de datos, o cualquier otro componente técnico del sistema.
